# Visual Upgrade Plan — Daily Video Digest

Мета: зробити відеоряд щоденного дайджесту живим і насиченим — замість статичних фото
з самописною графікою. Зміни тестуються на гілці `fix/visual-director` через ручні
рендери (skip_youtube), і потрапляють в щоденну автоматику ТІЛЬКИ після схвалення власника.

## План робіт

### Ітерація 1 (зараз)
- [ ] **П1. Відео-b-roll**: увімкнути Pexels-відео (код пошуку вже є, був вимкнений) і
      вплести кліпи у фразові блоки VisualBlockScene як рухомий фон (нове поле `bRollVideoSrc`).
- [ ] **П2. Насиченість кадрів**: Pexels-фото як доповнення для сегментів, де < 3 зображень.
- [ ] **П3. Кіно-стиль AI-кадрів**: генерація стильових FLUX-кадрів (Cloudflare Workers AI,
      безкоштовно) з єдиним stylistic-суфіксом на весь випуск для "бідних" сегментів.
- [ ] **П4. Тестовий рендер** за вчорашній день через GitHub Actions (mode=render,
      skip_youtube=true, гілка fix/visual-director) → mp4 у `output/test-renders/`.

### Ітерація 2 (після відгуку власника)
- [ ] **П5. Lottie-оверлеї**: набір безкоштовних анімацій у `remotion-video/public/lottie/`,
      компонент LottieOverlay, мапінг категорія/метафора → анімація.
- [ ] **П6. Переходи**: @remotion/transitions + motion-blur.
- [ ] **П7. Кінетична типографіка** ключових слів.

### Фіналізація (тільки після "мене влаштовує якість")
- [ ] Мерж fix/visual-director → main, деплой у щоденну автоматику.

## Правила тестування
1. Кожна ітерація = новий тестовий рендер за вчора, файл у `output/test-renders/`.
2. Порівняння з опублікованими відео на YouTube (те, що є зараз).
3. Жодних змін у main / щоденному пайплайні до фінального схвалення.
